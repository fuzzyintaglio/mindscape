# Experiments (temporary)

**HelloMindscape.app** is a throwaway test for Phase 7. It checks whether a small native app, delivered by `git pull`, can open on the work Mac and show Mindscape. It only displays the page from the local server: it doesn't start anything, change settings, or touch the vault. It will be deleted after the test.

- Source: `hello-app/main.swift`
- Rebuild (dev Mac): `experiments/hello-app/build.sh`

To try it: in Finder, open this folder and double-click **HelloMindscape.app**.
